## Purpose

The single most-duplicated machinery across the ecosystem: three ventures independently built
*sign-with-DST + canonical-JSON + verify*. `attest` unifies it into one auditable package that
**everything else signs with**. It is the base of the publish order (`attest → identity-server →
muffler → whiffin → hudhud`).

## Seeds (the API oracles — M1 derives from these)

- Oreoasis `apps/oreoasis-core-host/src/dsse.ts` (DSSE envelope sign/verify + PAE)
- Oreoasis `src/services/{witness-client,witnessed-chain-anchor,anchor-receipt-store}.ts` (witnessing + receipt store)
- Oreoasis `scripts/{standalone-verifier-entry,export-audit-bundle}.ts` (standalone verifier + bundle)
- Duedale `packages/ks-adapters/src/report/index.ts` (envelope sign/verify pattern; `kash-report-v1`)
- Indusland IPOE1 / IVFC1 formats (compat verification targets)

## Surface (sketch — confirm against seeds in M1)

1. **Core** — JCS canonicalization + Ed25519 sign/verify over **DSSE envelopes** (PAE); typed attestation payloads. Reuses `@kashscript/identity-core` canonical + signatures where they align.
2. **DST registry** — one canonical, versioned registry of domain-separation tags with owners. Register the live ones: `kash-grant-v1`, `kash-report-v1`, `indus.poe.v1.qr`, `indus.vfc.v1.cert`, hudhud action-ledger + identity-event DSTs. **New DSTs are added here first, by rule.**
3. **Witnessing** — Rekor client (primary) + OpenTimestamps (fallback) + offline stub; receipt-store **interface** (adapters stay consumer-side).
4. **Hash-chain helpers** — append-only chain link/verify (shared by Oreoasis ledger + Duedale grant chain).
5. **Standalone verifier CLI** — `bunx @kashscript/attest verify <bundle>`: verifies envelopes, chains, witness receipts on a machine that has never seen the producer.
6. **Compat verifiers** — for already-shipped venture formats (IPOE1, IVFC1, `kash-report-v1`) so existing artifacts verify through the same CLI.

## Standards conformance

in-toto/DSSE attestation envelopes; transparency-log anchoring via **Sigstore Rekor** (primary) or
**OpenTimestamps** (fallback). (ECOSYSTEM decision 5.)

## Stays venture-side (guard b, ADR-0016)

Issuance **policy** (who may sign what, when), storage adapters, JWKS hosting.

## Acceptance (met, M1)

Unit suite ports the behaviours of all three seeds; the CLI verifies a real exported Oreoasis
bundle **and** Duedale's `/report/report.json` **and** an Indusland IVFC1 sample — **offline**.

## Security

Round-1 red-team audit: [`attest-audit-r1.md`](attest-audit-r1.md). 6 findings; F2 (malformed-sibling
denial-of-verification), F3 (malformed-input crash-DoS), F5 (stale DID-format note) fixed with tests this
round. F1 (anchor-root injectivity) is a **wire-format** change deferred to a coordinated anchor-format v2;
F4 (default self-attestation posture) + F6 (unsigned row metadata) logged as documented non-guarantees.
